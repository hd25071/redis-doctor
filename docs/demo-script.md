# 3 分钟演示视频脚本

目标：让一个陌生人看完能回答"这个 Agent 准不准、凭什么"。

## 录制方式

```bash
# 终端录制（asciinema 或其他任意录屏工具）
asciinema rec docs/demo.cast -c "python rdctl.py demo --scenario S02"
# 或直接屏幕录制：窗口里依次执行下面的命令
```

演示用的故障可以换成任意场景（`python rdctl.py scenarios list`）。

## 现场问答备料

- **"这是大模型跑的吗？"** 不是，提交的数字来自确定性参考策略，用来做回归基线；
  真实模型命令在 `docs/evaluation.md`，README 里标注得很清楚。
- **"为什么不自动修复？"** 只读默认开放、写操作必须审批；L2 只生成命令。删除主节点 Pod
  会让副本全量同步甚至丢数据，所以它是 medium 风险、必须人工批准。
- **"RAG 提升了多少？"** 在手册覆盖的类别上 C 组 100%，在故意不写进手册的 4 类上 75%——
  提升是真的，但只在手册覆盖范围内；held-out 那一栏就是为了防止"背答案"。
- **"怎么证明它不是背答案？"** 三件事：held-out 类别、预算收紧实验、以及结论里的每条证据
  都必须指向真实 `call_id`（幻觉率由代码计算）。
